# Ручная проверка PLG-14: «компонент канала не установлен»

Проверяет владелец: при отсутствии файла набора канала учётка показывает честное состояние «Компонент канала не
установлен» (решение 2026-11-19 `docs/decisions/2026-11-19-components.md`), а не вечное «без связи». До PLG-15/17
состояние достижимо только установкой MSI без каналов (`CHANNELS=none`, PLG-13). Нужны права администратора.

1. Установить `postman-<версия>-windows-x64.msi` тихо без каналов: `msiexec /i <msi> /qn CHANNELS=none`. В
   `C:\Program Files\Postman` нет `postman-plugins-telegram.exe`.
2. Запустить Postman, «Настройки → Каналы», включить Telegram, «+ Добавить учётку», ввести номер — строка канала
   показывает «Компонент канала не установлен» (без автоповторов; кнопки установки ещё нет — она в PLG-15).
3. Положить `postman-plugins-telegram.exe` той же версии в `%LOCALAPPDATA%\Postman\Components` (каталог создать),
   нажать «Повторить» у учётки — канал поднимается (файл подхватывается из каталога компонентов, PLG-14).
4. Вернуть установку с каналами: `msiexec /i <msi> /qn` — файл в папке установки, канал работает; удалить файл из
   каталога компонентов, чтобы не мешал следующим проверкам.
