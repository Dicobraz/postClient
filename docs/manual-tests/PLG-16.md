# Ручная проверка PLG-16: офлайн-установка компонента из файла

Проверяет владелец: способ раскатки без интернета (решение 2026-11-19 `docs/decisions/2026-11-19-components.md`)
для пакетов без установщика. Нужен файл `postman-plugins-telegram-<ОС>-<арх>.zip` со страницы Releases **той же
версии**, что установленное приложение (после PLG-17 такие файлы публикуются с каждой версией). Интернет — не
нужен; права администратора — не нужны.

### Кнопкой (окно)

1. Установить Postman без каналов: `msiexec /i <msi> /qn CHANNELS=none` (или portable-zip).
2. «Настройки → Каналы», включить Telegram — «Компонент канала не установлен. Скачать · Установить из файла…».
3. «Установить из файла…» → выбрать файл компонента: строка исчезает, канал поднимается; в
   `%LOCALAPPDATA%\Postman\Components` — exe и маркер версии.
4. Архив без канального файла (например, обычный zip вложений) — «Не удалось скачать компонент: no channel
   component found in the archive», состояние остаётся, «Скачать»/«Установить из файла…» работают.

### Тихо (для раскатки, окно не нужно)

5. `postman.exe --install-component <файл.zip>` — консоль печатает `component installed: postman-plugins-telegram`,
   код выхода 0. Файл в `Components`, Postman можно запускать.
6. Чужой архив: код выхода 1, `component install failed: no channel component found in the archive`.
7. Без аргумента: код 2, подсказка про путь.
8. Сверка сборки (по желанию): подсунуть файл **другой** версии — установка пройдёт, но канал при включении
   поднимется «проблемой» (чужую сборку не пропускает рукопожатие `Hello`, PLG-02/14); правильный файл —
   «Повторить»/переустановка исправляет.
