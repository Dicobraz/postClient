# AUD-09: пределы модулей применяются хостом; «Не загружается» в настройках

Статус: 🤖 частично (2026-11-21): шаги 2, 3, 4 — сцены и тесты (`settings-viewers-broken`, юниты `viewers.rs`,
`tests/viewer.rs`); владельцу — 1, 5 (нужны модули `.wasm`: с импортом и с заявленными пределами).

Модули — в `%LOCALAPPDATA%\Postman\viewers` (пара `<имя>.json` + `<имя>.wasm`); журнал — `viewer: module not
loaded: …`.

1. Модуль с импортом (раздел Import в `.wasm`, например `env.log`): в «Настройках → Просмотр вложений» — строка
   «Не загружается: модуль просит доступ к системе» без выключателя, имя и версия — из описания; в журнале —
   отказ с путем. Файл с этим расширением модуль не открывает (карточка «нет просмотра»).
2. Модуль с `limits` в описании (например `"memory": 1048576`, `"fuel": 1000000`): просмотр файла, требующий
   больше заявленного (рост памяти, длинный вход или ответ), — отказ просмотра, а не работа за обещанным.
3. Описание с `limits` сверх общих (`"memory": 1073741824`) — «Не загружается: пределы заявлены сверх общих».
4. Файл `.wasm` не двоичный (или `.wasm` нет рядом с описанием) — «Не загружается: файл модуля не годится»;
   сломанный `.json` — «Не загружается: описание не годится».
5. Нерабочие строки — после рабочих, в порядке каталогов (системный, затем пользовательский); после починки
   файла и перезапуска модуль — обычной строкой с выключателем.
