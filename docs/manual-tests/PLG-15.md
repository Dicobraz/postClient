# Ручная проверка PLG-15: докачка компонента канала

Проверяет владелец **после PLG-17** (нужны компонентные ассеты `postman-plugins-<канал>-<ОС>-<арх>.zip` +
`.minisig` в выпуске той же версии, что установленное приложение). Сценарий решения 2026-11-19
`docs/decisions/2026-11-19-components.md`: приложение само качает файл набора Telegram из выпуска и поднимает
канал. Нужен интернет; проверять на машине без прав администратора (типичный случай).

1. Установить Postman **без каналов** (PLG-13): `msiexec /i <msi> /qn CHANNELS=none`. Файла
   `postman-plugins-telegram.exe` в `C:\Program Files\Postman` нет.
2. «Настройки → Каналы», включить Telegram: на панели — «Компонент канала не установлен. Скачать».
3. Нажать «Скачать»: строка показывает ход («Скачивается компонент: N %» с «Отменить»); по завершении строка
   исчезает, канал поднимается сам — в `%LOCALAPPDATA%\Postman\Components` лежат `postman-plugins-telegram.exe`
   и маркер версии. Вход в Telegram работает.
4. Обновить Postman (самообновление или следующий MSI): на панели Telegram — «Компонент канала обновился вместе
   с программой: скачайте заново. Скачать»; после скачивания канал работает, старый файл заменён.
5. Отказы: сеть отрубить на шаге 3 — «Не удалось скачать компонент: …» с возможностью повторить; «Отменить»
   посреди скачивания возвращает к «Скачать».
6. Политика `AllowChannelTelegram = 0`: панели Telegram нет вовсе — скачивание недоступно (как и канал).
