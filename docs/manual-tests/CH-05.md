# CH-05. Канал Matrix — вход, комнаты, шифрованная переписка

Статус: ⏳ (ручная проверка — владелец, тестовая учётка на matrix.org или своём сервере Matrix; второе устройство —
Element или другое приложение Matrix, где та же учётка уже вошла и настроены кросс-подпись и резервная копия ключей)

Подготовка: канал — процесс набора `postman-plugins-matrix` (PLG-04): файл набора лежит рядом с `postman`
(пакеты PLG-03) или собирается из дерева (`cargo build -p postman-gpui -p postman-plugins-matrix`); признаков сборки
больше нет — канал включают настройка и политика `AllowChannelMatrix`, без файла набора у учётки «проблема → причина»
(размер — `docs/SIZE.md` №15; поведение процесса — `PLG-04.md`). Вид бесед — CH-04: до него беседы и сообщения видны
по журналу (`Debug`) и в базе профиля; здесь проверяется вход, шифрование, проверка устройства, резервная копия
и настройка «Шифрованные беседы».

1. «Настройки → Аккаунты» → «Каналы бесед»: «Matrix» выключен. Включить — «Добавить учётку Matrix» и строка
   «Шифрованные беседы». Политика `AllowChannelMatrix = 0` (реестр `Software\Policies\Pets\Postman`) — строки Matrix
   нет; `= 1` — включён, выключатель недоступен, «Задано политикой организации».
2. «Добавить учётку Matrix» → сервер с опечаткой (`matrix.orgx`) — «Сервер Matrix не найден…». `matrix.org` →
   «Имя пользователя»; неверный пароль — «Неверное имя или пароль», шаг тот же; верный — карточка закрылась, строка
   учётки: имя, «Подключение…» → «В сети». Ввод `@имя:matrix.org` сразу на шаге сервера — сразу пароль.
3. Вход через браузер: «Добавить учётку Matrix» → сервер → «Войти через браузер» — открылась страница входа сервера;
   войти там — в браузере «Вход выполнен — вернитесь в Postman», в Postman — учётка «В сети». Сервер только с SSO —
   браузер открывается сразу после шага сервера. Не входить 5 минут — «Вход в браузере не завершён».
4. В Element на втором устройстве — «Сеансы»: новый сеанс «Postman». Перезапуск Postman — учётка «В сети» без входа
   (секрет — в диспетчере учётных данных, запись `Postman channel matrix @имя:сервер`; файлов SDK рядом с базой нет:
   ни `*.sqlite3`, ни папок matrix-sdk в папке данных).
5. Комнаты: журнал `Debug` — `channel: conversations changed`; личные, группы, пространства (база профиля:
   `chan_account`, `conv`). С телефона написать в комнату — в журнале `conversations changed` за секунды; правка,
   реакция, удаление (redaction) с телефона — так же.
6. Шифрованная переписка: в Element — шифрованная комната с собой и вторым человеком; написать до подключения
   Postman и после. Новые сообщения после входа — расшифрованы (в базе текст при «Хранить и искать»). Старые (до
   входа Postman) — заглушки «не расшифровано», пока нет ключей.
7. Проверка устройства: строка учётки → «Проверить это устройство» → «Подтвердите запрос на другом устройстве»; в
   Element — принять запрос → в Postman семь символов с подписями, такие же в Element → «Совпадают» (и в Element) —
   «Устройство проверено». В Element сеанс «Postman» — проверенный. «Не совпадают» — «Проверка отменена…». Учётка без
   кросс-подписи — «У учётки не настроена проверка устройств…».
8. Резервная копия: «Восстановить ключи» → ключ восстановления (или фраза) из Element → «Ключи восстановлены…»;
   старые сообщения шифрованной комнаты из п. 6 приходят снова расшифрованными (тот же id — строка в базе та же, не
   вторая). Неверный ключ — «Ключ или фраза не подошли», поле осталось.
9. «Шифрованные беседы»: «Хранить, не искать» — поиск по слову из шифрованной комнаты пуст, из обычной — находит;
   «Только в памяти» — в базе у сообщений шифрованных комнат нет текста (проверка — после перезапуска при выключенной
   сети: текст пуст), пока Postman запущен — текст есть; обратно «Хранить и искать» — текст из памяти снова в базе и в
   поиске. Политика `ChannelE2EStorePlaintext = 0|1|2` — выбор закреплён, «Задано политикой организации».
10. Связь: выключить сеть — «Нет связи, повтор через N с»; включить — «В сети», пропущенное пришло (догон от курсора).
11. «Выйти» — строка учётки пропала, в Element сеанса «Postman» нет, записи в диспетчере учётных данных нет; данных
    `chan/matrix/…` в базе профиля нет. Выключить «Matrix» — учётки не подключаются, данные остаются до «Выйти».
