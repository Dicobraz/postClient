# T2-48. Выбор адресной книги в форме контакта

Статус: ⏳ (вид — 🤖 снимок `contact-edit` не меняется; живой сервер с несколькими книгами — владелец)

1. Сервер с одной адресной книгой (The Post / Stalwart): «Контакты» → «Новый контакт» — поле «Адресная книга»
   показывает имя книги (или «Мои контакты»), без выбора. Сохранить — контакт в книге по умолчанию.
2. Сервер с несколькими книгами (JMAP — книги The Post; CardDAV — коллекции; Exchange — подпапки «Контактов»):
   «Новый контакт» → «Адресная книга» — меню книг, по умолчанию — книга сервера. Выбрать другую, сохранить —
   контакт в выбранной книге (проверить другим клиентом: Outlook, веб-почта).
3. Правка контакта: поле — только показ, перенос между книгами не предлагается; сохранить — контакт в своей книге.
4. Сервер без списка книг (ошибка чтения): форма работает, пишет в книгу по умолчанию, раздел не падает.
