## Изменения

Волны плагинов — протоколы уходят из `postman.exe` в файлы набора (ADR 0013, решение владельца 2026-11-16
«plugin-files»: общий файл — почта и каталог вместе, Telegram и Matrix — своими файлами, Matrix в 0.2.0 не входит):

- **PLG-05 — Telegram процессом** (PR #12): канал Telegram — отдельным файлом набора `postman-plugins-telegram`,
  своим файлом набора; `postman.exe` не задет (SIZE №16). Дополнить после сверки: что ещё вошло.
- **PLG-06 — LDAP процессом** (PR #13): каталог — в общий файл набора `postman-plugins` (SIZE №17). Дополнить.
- **PLG-07 — области и DAV процессом** (PR #14): CalDAV/CardDAV — в общий файл набора (SIZE №18). Дополнить.
- **PLG-08 — EWS процессом** (PR #15, в работе): почтовый путь — услуги ядра, EWS — отдельным процессом.
  Дописать после слияния.
- PLG-09…12 и остальные волны до выпуска — дописать; «Исправлено» и «Что нового» — на финальной сверке.

## Бюджеты/размеры

Текущие из `docs/SIZE.md` (замеры Linux x86_64, school-99, профиль release; бюджет `postman.exe` ≤ 74 МиБ —
про Windows, Linux-замер — база «до/после» для PLG-12):

- `postman.exe`: бюджет ≤ 74 МиБ (№10); воркер ≤ 12 МиБ, просмотрщик ≤ 2 МиБ (№9). Вынос каналов exe не задет:
  82,20 (base16) → 80,00 (№16) → 79,38 (№17) → 79,07 МиБ (№18).
- Набор плагинов: `postman-plugins` (демо + каталог + DAV) — 11,24 МиБ из оценки ~15 МиБ на полный общий файл
  (№14; №18 — перед почтовыми волнами PLG-08…10 вернуться к бюджету, вероятно превышение — решение о бюджете
  перед выпуском, SIZE-01).
- Отдельные файлы набора: `postman-plugins-telegram` — 3,76 МиБ (№16), `postman-plugins-matrix` — 22,73 МиБ
  (№15; Matrix в выпуск 0.2.0 не входит — решение 2026-11-16).
