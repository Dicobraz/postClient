Сверено с `main`; изменения с прошлого выпуска — `git log v0.1.0-beta.7..v0.2.0`. Первый стабильный выпуск: каналы
Telegram и Matrix, «Медиа беседы», протоколы — отдельными процессами набора (ADR 0013), каталог компонентов с
офлайн-установкой, каналы в MSI по умолчанию.

## Что нового

- **Каналы — Telegram и Matrix** в приложении: беседы каналами (дерево, список, лента чата), альбомы, папки по
  правилам, умные папки, кнопки ботов и опросы, «Настройки → Каналы» (CH-03/04/05). MSI несёт компоненты обоих
  каналов и ставит по умолчанию (состав раскатки — свойство `CHANNELS`, PLG-13); остальные пакеты — без файлов
  каналов: приложение докачивает их из выпуска (PLG-15/17).
- **«Медиа беседы»** — отдельный режим вместо ленты: фото, видео и файлы беседы одним экраном; вложения можно
  кидать прямо из поля ввода (MED-02).
- **Запуск быстрее, основной файл меньше**: протоколы почты и каталога (IMAP, SMTP, JMAP, Exchange, LDAP, CalDAV/
  CardDAV) и каналы работают отдельными процессами и поднимаются по требованию (ADR 0013); в основной файл они
  больше не входят — он легче, первый кадр не медленнее (PLG-01…12).
- **Компоненты** — «Настройки → Компоненты»: каталог с состоянием («установлен», «нет»), докачка из выпуска и
  офлайн-установка «из файла», тихий ключ `--install-component` (PLG-14…16).
- **Кнопки окна** — по настройке ОС; на Windows можно включить раскладку macOS (кнопки слева) (LIN-08).
- **Стабильная версия** — первый выпуск канала «Стабильный»; беты 0.1.0-beta.5 и новее предложат её сами.

## Изменения

Каналы и медиа:

- **CH-05 — канал Matrix**: вход, комнаты, шифрование, проверка устройства (#698).
- **CH-04 волна 1** — беседы каналов: дерево, список, лента чата (#699); **волна 2** — умные папки, «Настройки →
  Каналы», кнопки ботов и опросы (#700); довесок `Action::Extra` (#696); дизайн каналов и «Медиа беседы» (#697).
- **CH-03 — Telegram**: альбомы, папки по правилам, кнопки и опросы в extra (#695).
- **MED-02 — «Медиа беседы»**: режим вместо ленты; вложения из поля ввода чата (#702).

Плагины отдельными процессами (ADR 0013, решение владельца 2026-11-16 «plugin-files»):

- **PLG-01** — механизм процессов `postman-proc`, профиль песочницы «сеть без файлов» (#705).
- **PLG-02** — хост плагинов, договор каналов по обмену, демо-канал процессом; замер до/после — первый кадр без
  цены, старт процесса ~50 мс тёплым (#3).
- **PLG-03** — набор `postman-plugins` в пакетах трёх ОС (#8).
- **PLG-04** — канал Matrix — отдельным файлом набора `postman-plugins-matrix` (#9), файл в пакеты (#16).
- **PLG-05** — Telegram процессом и своим файлом набора (#12).
- **PLG-06** — каталог LDAP процессом (#13).
- **PLG-07** — `serde` на командах/событиях синхронизации (#11); области (календарь, задачи, контакты) через ядро,
  DAV процессом, публичные загрузки процессом (#14).
- **PLG-08** — услуги ядра (хранилище/воркер/печать/индекс) почтовому пути, EWS отдельным процессом (#15); опись
  услуг (#10).
- **PLG-09** — IMAP + SMTP процессом (#27).
- **PLG-10** — JMAP процессом; в `postman.exe` сетевого стека протоколов больше нет (#30).
- **PLG-11** — уборка: `postman-gpui` не зависит ни от одного `postman-backend-*`; слои и наборы в документах (#34).
- **PLG-12** — приёмка: паника задачи плагина отвечает отказом по обмену (тест), порог выгрузки без учёток —
  5 минут (ADR 0013), замер «до/после» — первый кадр 259 → 274 мс (шум), с набором 231 мс, старт набора 12–16 мс,
  память набора 8 МиБ (#35).
- **PLG-13** — каналы в MSI: по умолчанию всё, состав раскатки `CHANNELS`, выбор переживает обновления (#28).

Компоненты и выпуск:

- **PLG-14** — каталог компонентов, «компонент не установлен» (#29).
- **PLG-15** — докачка компонента канала из выпуска (#31).
- **PLG-16** — офлайн-установка компонента «из файла», `--install-component` (#32).
- **PLG-17** — базовые пакеты (zip, dmg, deb, rpm, AppImage) без файлов каналов — они докачиваются из выпуска;
  в выпуск — компонентные zips `postman-plugins-<канал>-<ОС>-<арх>.zip` (#33).

Прочее:

- **LIN-08** — кнопки окна по настройке ОС; слева — раскладка macOS (#7).
- **T2-48** — выбор адресной книги в форме контакта (#5).
- **MAC-08** — вкладки — только открытые объекты на всех ОС (#704).
- **SIZE-13** — состав канала Matrix и дубли зависимостей: без патча убрать нечего (#706); бюджеты `postman.exe`
  ≤ 74 МиБ (№10), opt-level «z» крейтам Matrix (№12).
- **CI** — артефакты сборки по файлу (#694); ключ приложения Telegram в release-сборках (#692); авто-доска
  Project №1 — PR и issues сами встают в проект (#26); снимки macOS — протяжка сцены по разным точкам (#4).
- **BUG-fragment-select** — фикс выделения фрагмента, снимки macOS зелёные (#6).
- **Зависимости** — html5ever 0.39→0.40.1 (#2), mail-send 0.6.2→0.7.0 (#1).

## Исправлено

- Выделение фрагмента текста терялось при коротком перетаскивании — метка «line-first», докрутка к границе
  строки (BUG-fragment-select, #6).
- Кнопки окна на Windows шли вразрез с настройкой ОС; раскладка macOS (слева) была недоступна (LIN-08, #7).
- На macOS-раннерах снимки падали из-за одинаковой точки протяжки сцены — точки разнесены (#4).
- Паника в задаче процесса плагина оставляла интерфейс без ответа (зависание до сторожа) — теперь отказ по
  обмену сразу (PLG-12, #35).

## Бюджеты/размеры

Из `docs/SIZE.md` (замеры Linux x86_64, school-99, release; бюджет `postman.exe` ≤ 74 МиБ — про Windows,
Linux-замер — база «до/после»):

- `postman.exe`: **72,91 МиБ** (№21) — протоколы и `reqwest`/`rustls` вне дерева; бюджет ≤ 74 не задет
  (82,20 base16 → 80,00 №16 → 79,38 №17 → 79,07 №18 → 77,88 №19 → 76,68 №20 → 72,91 №21).
- Общий набор `postman-plugins` (демо + каталог + DAV + EWS + IMAP + JMAP): **17,92 МиБ** против оценки ~15 из
  №14 — **предложение ≤ 19 МиБ, решение владельца** (SIZE-01); `postman-plugins-telegram` 4,27 (≤ 5),
  `postman-plugins-matrix` 23,24 (≤ 24; в выпуск 0.2.0 не входит, ставится компонентом).
- Воркер ≤ 12 МиБ (Windows-замер №9) — Linux-факт 12,73; просмотрщик ≤ 2 — факт 1,97.
- SIZE-01 `panic = "abort"` для процессов плагинов: cargo запрещает `panic` в `profile.package` — нужен
  профиль `[profile.dist]` и одна строка в release-job (`.github`) — за владельцем; рецепт в `docs/SIZE.md`.
