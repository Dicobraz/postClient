## Задача
- «Нужен способ раскатки без интернета» (решение владельца 2026-11-19): Windows — MSI с `CHANNELS` (PLG-13);
  остальные пакеты — файл выпуска (`postman-plugins-<канал>-<ОС>-<арх>.zip` со страницы Releases) устанавливает
  приложение: кнопкой «Установить из файла…» рядом с «Скачать» или тихо — `postman --install-component <файл>`.
- Подпись локального файла не проверяется (его приносит сам администратор); чужую сборку не пропустит сверка
  сборки в `Hello` — канал с ней поднимется «проблемой». Маркер версии пишется той же строкой, что у докачки.

## Сделано
- `components.rs`: `install_from_file` (панель: диалог выбора файла, установка в фоне, итог как у докачки),
  `install_file_headless` / `install_at` (CLI, без окна и сети — набор ищется среди канальных файлов архива),
  второй ссылкой на панели для состояний «не установлен»/«чужая версия»/«отказ». Тест `install_from_file_places_the_set`.
- `main.rs`: флаг `--install-component <файл.zip>` — печатает результат в консоль и выходит (до окна,
  одиночного экземпляра и сети); строка в `--help`. Ошибка при запущенной программе — файл занят, не портится.
- Тексты: `comp-from-file` (ru/en).
