## Задача
- «Компоненты доставлять прямо из приложения, перечень тоже докачивается» (решение владельца 2026-11-19
  `docs/decisions/2026-11-19-components.md`): включил канал — файла нет → кнопка «Скачать»; приложение качает
  файл набора из **своего** выпуска той же версии и запускает канал.
- Перечень — список релизов того же репозитория (`pets-update::releases_url`), файл — `postman-plugins-<канал>-<ОС>-<арх>.zip`,
  подпись — `.minisig` теми же ключами, что у самообновления (`Updater::verify`). Сеть — только по кнопке и только
  на выпуск своей версии; после самообновления файл прошлого выпуска помечается «обновить» (маркер версии).

## Сделано
- `app-gpui/src/components.rs` (новый): состояние компонента (`Present`/`Offered`/`Stale`/`Busy`/`Absent`/`Failed`),
  поток скачивания — своим `Transport`-ом крейта обновления (файлы свои, проверка — общая `Updater::verify`
  вшитыми ключами), распаковка крейтом `zip` (уже зависимость интерфейса — сжатие упаковке не важно), маркер
  версии `<набор>.txt` в каталоге компонентов; на Windows каталогу даётся ACE `ALL APPLICATION PACKAGES`
  (icacls, как в `install.ps1`) — иначе песочница не прочтёт exe. Отказы — в журнал и строку настроек.
- Хост: `Host::retry(id)` (core) — после установки компонента «проблема» снимается без пользователя
  (`component_ready` в корне, PLG-14: файл подхватывается из каталога компонентов).
- Экраны: строка компонента в панелях Telegram и Matrix (`row`): нет файла — «Скачать», чужая версия —
  «скачайте заново», ход — проценты + «Отменить», отказ — причина + «Скачать». Тексты `comp-*` (ru/en) в
  `channels.ftl`.
- Тесты: имена файлов по шаблону выпуска, разбор перечня (свой выпуск, чужой набор/выпуск — нет), распаковка
  zip (свой файл читается, чужой — ошибка), маркер версии (`Stale` после обновления). 765/765 с PLG-14.

## Нюансы сборки (для следующих волн)
- В тестовых модулях не делать `use super::*` поверх `use gpui_kit::*` родителя: глоб-импорты уводят раскрутку
  rustc в глубину — «recursion limit»/переполнение стека даже на тривиальном тесте; только явные имена.
- `serde_json::json!` в тестах `postman-gpui` — тоже уводит глубину; собирать `Value` программно.

## Не сделано (адресно)
- Компонентные ассеты в выпуске публикует PLG-17 — до них кнопка честно отвечает «нет в выпуске»/отказом сети.
  Ручная проверка — после PLG-17 (`docs/manual-tests/PLG-15.md`).
- Офлайн-установка из файла и `--install-component` — PLG-16; пакеты без файлов каналов — PLG-17.
