> Сверка макетов T2-G («Контакты», `Contacts`): поле «Адресная книга» формы сейчас только показывает «Мои контакты».

## Что нужно
- Поле — выбор из книг сервера (JMAP `AddressBook/get`, CardDAV — коллекции адресных книг, Exchange — папки
  контактов); сохраняется сейчас в книгу по умолчанию (`Client::create_contact`).
- Событие со списком книг и книга в `Command::SaveContact` (только у новой карточки; перенос между книгами — нет).

## Сделано
- Договор: `Event::ContactBooks(Vec<ContactBook>)` (id, имя, «по умолчанию») — ответ на `Command::Contacts`;
  `Command::SaveContact` получил `book` (только у новой карточки, `None` — книга по умолчанию). Точки построения
  команды (связь каналов с карточкой, ADR 0012) и тесты путей — `book: None`.
- Пути: JMAP — `AddressBook/get`, новая карточка в выбранную книгу (`create_contact(book, …)`); CardDAV — коллекции,
  доступные для записи («по умолчанию» — первая), PUT в выбранную; Exchange — папка «Контакты» и подпапки
  (`GetFolder`+`FindFolder`; папки почты и галереи — не книги), `CreateItem` в выбранную. Ошибка чтения книг — не
  помеха разделу: пишет в книгу по умолчанию.
- Форма нового контакта: «Адресная книга» — выбор (книг две и больше), без выбора — книга по умолчанию, правка и
  единственная книга — только показ; Esc закрывает меню. Демо — «Мои контакты» без выбора. События дополнительных
  учётных записей книги не перебивают основную (`live.rs`).
- Тесты: подменной Exchange — список книг (`Contacts` по умолчанию, «Коллеги») и создание в выбранной папке;
  формы — выбранная книга, иначе по умолчанию, книг нет — «Мои контакты». Ручная проверка — `docs/manual-tests/T2-48.md`.

## Не сделано (адресно)
- Перенос контакта между книгами: правка остаётся в своей книге (в карточке книги нет).
- Книга у формы группы («Новая группа»): группа пишется в книгу по умолчанию.
- Живой сервер (JMAP Stalwart, CardDAV, Exchange) — ручная проверка владельца.
