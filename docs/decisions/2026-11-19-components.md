# Компоненты каналов: установка, раскатка, докачка

Владелец, 2026-11-19 — про Telegram и Matrix (файлы наборов `postman-plugins-telegram`, `postman-plugins-matrix`,
PLG-04/05), вместо «компонента установщика» из решения 2026-11-16 «plugin-files»:

- «При запуске установщика ставится всё, а если каналы не нужны, их можно выключить — так логичнее для обычного
  пользователя»: MSI ставит оба канала по умолчанию, выбирать ничего не нужно. Неиспользуемый канал не запускается
  вовсе (ADR 0013 — плагины по запросу): «выключить» для пользователя — не включать канал в настройках приложения.
- «Опции CLI по установке каналов типа CHANNELS»: состав каналов для сетевой раскатки задаёт свойство MSI
  `CHANNELS` — точный список (`CHANNELS=Telegram`, `CHANNELS=Telegram,Matrix`), `none` или пустое — без каналов,
  не задано — все. Выбор переживает обновления в обе стороны (маркеры в реестре), `REMOVE=имя` снимает канал.
- «Внешние компоненты доставлять прямо из приложения, перечень тоже докачивается»: в пакетах без установщика
  (zip Windows, macOS, Linux) файлов каналов в комплекте нет — файл набора докачивает само приложение из выпуска
  той же версии (перечень — из того же выпуска), карточки PLG-14…PLG-17.
- «Нужен способ раскатки без интернета»: Windows — тот же MSI с `CHANNELS` (файлы каналов внутри пакета); другие
  ОС — установка файла набора из выпуска («Установить из файла», `--install-component`).

Механика MSI и проверка — карточка PLG-13; докачка из приложения — PLG-14…PLG-17. Продолжает решения
2026-11-16 «plugin-files» (отдельные файлы наборов) и 2026-11-07 «installer-msi-winget» (один установщик — MSI).

## Что из этого следует

- **Обычному пользователю** (двойной щелчок по MSI, winget) каналы ставятся всегда; включение канала — по-прежнему
  в настройках приложения, без учётки процесс канала не поднимается.
- **Раскатка по сети** — тихая установка без мастера: `msiexec /i postman.msi /qn` (всё) или `CHANNELS=none`
  (только почта и каталог); частичный состав — `CHANNELS=Telegram,Matrix`.
- **Состав переживает обновления**: при самообновлении (`msiexec /passive` без свойств) и больших обновлениях MSI
  выключенное через `CHANNELS`/`REMOVE` остаётся выключенным, включённое — ставится.
- **«Из сети не скачиваются» (ADR 0013 п. 7) сужается**: докачивает только само приложение, из собственного
  выпуска той же версии, с подписью minisign; отдельного магазина плагинов и чужих источников нет.
- **Zip/deb/rpm/AppImage/dmg — база без файлов каналов** (PLG-17): их вес — в докачанном файле, установка по
  умолчанию легче на ~26 МиБ; в MSI файлы остаются (офлайн-раскатка).
